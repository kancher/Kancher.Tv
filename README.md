# Kancher.Tv - Реконструкция кодовой базы

## Обзор

Kancher.Tv ~ "Вижу" МИР так..
Версия [2.0] от 2025.10.25
Севастополь | Российская Федерация

Это персональное интерактивное портфолио Сергея Канчера, медиа-профессионала с более чем 15-летним опытом работы в телевидении и медиа-производстве. Проект представляет собой современное веб-приложение с AI-ассистентом, таймлайном карьеры и галереей проектов.

## Структура проекта

- `index.html` - основная HTML-структура
- `style.css` - стили и оформление
- `script.js` - интерактивность и AI-логика
- `images/` - изображения и иконки
- `RECONSTRUCTION.md` - подробная документация по реконструкции
- `SUMMARY.md` - техническое резюме проекта

## Особенности

- 🎨 Современный дизайн с темной темой
- 🤖 Встроенный AI-ассистент с локальной базой знаний
- 📱 Полностью адаптивный дизайн
- ⚡ Анимации и интерактивные элементы
- 📖 Таймлайн карьеры с 2010 по 2025 год
- 🎯 Галерея ключевых проектов

## Технологии

- HTML5
- CSS3 (с переменными, градиентами, Grid/Flexbox)
- JavaScript (ES6+)
- Intersection Observer API
- Fetch API
- Google Fonts

## Функциональность

- Случайные цитаты при загрузке
- Анимации при прокрутке
- AI-чат-бот с возможностью подключения к внешнему API
- Плавная навигация
- Параллакс-эффекты
- Адаптивный дизайн для всех устройств

## Установка

Проект не требует установки - это статический веб-сайт. Просто откройте `index.html` в браузере или разместите на любом веб-сервере.
