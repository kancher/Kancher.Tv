# Kancher.Tv - Техническое резюме

## Основная информация
- **Название проекта**: Kancher.Tv
- **Версия**: [2.0] от 2025.10.25
- **Автор**: Сергей Канчер
- **Тип проекта**: Персональное портфолио с AI-ассистентом
- **Местоположение**: Севастополь, Российская Федерация

## Назначение
Интерактивное портфолио медиа-профессионала, демонстрирующее карьерный путь, проекты и философию создания медиаконтента.

## Архитектура

### Frontend
- **HTML5** - семантическая разметка
- **CSS3** - современные стили с переменными, градиентами и адаптивностью
- **JavaScript (ES6+)** - интерактивность и AI-логика

### Структура данных
- **Цитаты** - массив из 10 философских цитат
- **База знаний** - 30+ категорий с ответами для AI-ассистента
- **Резервные ответы** - 13 вариантов для неизвестных запросов

### Компоненты

#### 1. Hero-секция
- Аватар пользователя
- Имя и профессиональное описание
- Слоган: "Создаю мощнятские штуки, которые заходят [ну почти]"
- Индикатор прокрутки

#### 2. Таймлайн карьеры
- Интерактивная шкала с 2010 по 2025 год
- Описания мест работы с поэтическим форматированием
- Анимации при прокрутке

#### 3. Галерея проектов
- 9 ключевых проектов с описаниями
- Карточки с hover-эффектами
- Адаптивная сетка

#### 4. Образование и навыки
- Информация об образовании (СевГУ)
- Категории навыков: производство, пост-продакшн, контент, другое

#### 5. AI-ассистент
- Встроенный чат-бот с кнопкой активации
- Локальная база знаний
- Возможность подключения к внешнему API
- Поддержка естественного языка

## Ключевые технологии

### CSS
- CSS-переменные для темизации
- Flexbox и Grid для адаптивности
- CSS-анимации и переходы
- Пользовательские свойства для темной темы

### JavaScript
- DOM API для манипуляции элементами
- Intersection Observer для анимаций при скролле
- Fetch API для внешних запросов
- Классы ES6 для структурирования кода

### Дизайн-паттерны
- Локальная база знаний для AI
- Резервные ответы
- Адаптивная типографика
- Поэтическое форматирование текста

## Функциональные возможности

### Анимации и эффекты
- Появление элементов при прокрутке
- Hover-эффекты для карточек
- Параллакс-эффект для героя
- Плавная прокрутка к якорям

### Интерактивность
- AI-чат с естественным языком
- Адаптивный дизайн для мобильных устройств
- Кнопки социальных сетей
- Интерактивный таймлайн

### Персонализация
- Случайные цитаты при загрузке
- Персонализированные ответы AI
- Темная тема по умолчанию

## Кодовая организация

### HTML
- Четкая семантическая структура
- Секции с уникальными ID
- Поддержка якорных ссылок

### CSS
- Модульная структура стилей
- Повторяющиеся компоненты
- Адаптивные брейкпоинты

### JavaScript
- Модульная архитектура
- Класс для AI-чата
- Локальные базы данных
- Обработчики событий

## Особенности реализации

1. **AI-ассистент** - уникальная функция с локальной базой знаний
2. **Поэтическое форматирование** - уникальный способ подачи информации
3. **Адаптивный дизайн** - корректное отображение на всех устройствах
4. **Анимации при скролле** - использование Intersection Observer API
5. **Темная тема** - современный подход к дизайну

## Зависимости
- Google Fonts (шрифт Inter)
- Нет внешних JavaScript-библиотек

## Заключение
Проект представляет собой современное интерактивное портфолио, объединяющее профессиональную информацию с персональной философией и инновационным подходом к взаимодействию с посетителями через AI-ассистента.
