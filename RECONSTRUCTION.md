# Кодовая база Kancher.Tv - Реконструкция

## Обзор проекта

Kancher.Tv - это персональный веб-сайт Сергея Канчера, медиа-профессионала с более чем 15-летним опытом работы в телевидении и медиа-производстве. Сайт представляет собой интерактивное портфолио, включающее таймлайн карьеры, список проектов, информацию об образовании и навыках, а также AI-ассистента.

## Структура файлов


## Подробное описание компонентов

### 1. index.html

Основная HTML-структура сайта, включающая:

- **Hero секция**: Введение с аватаром, именем и слоганом
- **Таймлайн опыта**: История карьеры с 2010 по 2025 год
- **Ключевые проекты**: Галерея важных проектов
- **Образование и навыки**: Информация об образовании и профессиональных навыках
- **Цитата**: Случайно выбираемая философская цитата
- **Проекты в работе**: Текущие и планируемые проекты
- **О себе**: Личная информация
- **Контакты**: Социальные сети и контактная информация
- **AI чат-бот**: Интерактивный помощник

### 2. style.css

Современные стили с использованием:

- CSS-переменных для темизации
- Flexbox и Grid для адаптивного дизайна
- Анимаций и переходов
- Адаптивности под мобильные устройства
- Градиентов и эффектов размытия

### 3. script.js

Интерактивные функции:

- Случайные цитаты при загрузке
- Анимации при прокрутке
- AI-ассистент с локальной базой знаний
- Чат-бот с возможностью подключения к внешнему API
- Плавная прокрутка
- Параллакс-эффект

## Особенности реализации

### AI-ассистент
- Использует локальную базу знаний с более чем 30 категориями
- Имеет резервные ответы при отсутствии знаний по теме
- Может подключаться к внешнему API через Cloudflare Workers
- Поддерживает естественный диалог и понимание контекста

### Дизайн-философия
- Темная тема с акцентными цветами
- Поэтическое форматирование текста
- Анимации появления элементов
- Адаптивный дизайн для всех устройств
- Интерактивные элементы с эффектами

### Технические особенности
- Чистый HTML/CSS/JS без внешних зависимостей (кроме Google Fonts)
- Использование современных CSS-фич (переменные, градиенты, grid)
- Intersection Observer для анимаций при скролле
- Адаптивные изображения и типографика
